# Android Application : Smart Contactor

A lightweight and modern Android contact management application built with **Kotlin** and **Jetpack Compose**. It allows users to smoothly store, view, update, and delete their contacts along with custom profile pictures stored locally.

---

## Features

* **Jetpack Compose:** Modern, declarative UI built entirely with Compose.
* **Local Database:** Uses **Room Database** with Kotlin Coroutines & Flow for reactive and asynchronous data handling.
* **Image Management:** Pick and copy contact images directly into internal storage using `ActivityResultContracts`.
* **Navigation:** Seamless screen transitions using Jetpack Navigation Compose.
* **Material Design 3:** Clean and intuitive modern UI components.

---

## Tech Stack

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Architecture Components:** 
  * ViewModel & LiveData / Flow
  * Room Persistence Library
* **Image Loading:** Coil
* **Asynchronous:** Coroutines
